# SkyLauncher 🚀

**SkyLauncher** — автономный универсальный игровой лаунчер с открытым исходным кодом, вдохновленный интерфейсом Hydra Launcher.

## 🌟 Ключевые возможности

1. **Мультиязычный интерфейс (i18n)**:
   - 🇬🇧 Английский (English)
   - 🇷🇺 Русский (Русский)
   - 🇮🇹 Итальянский (Italiano)
   - Выбор языка при первом запуске и быстрое переключение в любой момент.

2. **Автономность (Standalone Edition)**:
   - Полное отсутствие обязательных аккаунтов или авторизаций.
   - Локальное хранение всех настроек и библиотеки игр.
   - Облачная синхронизация пользовательских настроек через Supabase.

3. **Реальный торрент-движок**:
   - Встроенный клиент на базе WebTorrent с автоматическим определением завершения.
   - Механизм освобождения дескрипторов файлов (`destroyStore: false`) перед запуском `.exe`, предотвращающий ошибку `EBUSY / Файл занят другим процессом`.
   - Поддержка внешних клиентов (qBittorrent, uTorrent).

4. **Автоматизация инсталляторов (Экспериментально)**:
   - Функция «Автоматически пройти setup.exe».
   - Фоновый запуск инсталляторов игр, отслеживание распаковки и авто-нажатия кнопок.

5. **Официальный каталог и постеры HD**:
   - Поддержка источников Hydra Links (JSON репозитории).
   - Интеграция со Steam Web API для получения HD-баннеров и постеров в реальном времени.

6. **Многоуровневый стек технологий**:
   - **TypeScript & React**: UI компоненты, анимации, адаптивная сетка.
   - **Electron & Node.js**: Фоновые воркеры, IPC, работа с процессами.
   - **Rust / C++ / C**: Системные оптимизации для работы с WinAPI и подсчета контрольных сумм.

## 🛠️ Структура проекта

```text
build/src/
├── electron/                 # Главный процесс Electron и фоновые скрипты
│   ├── main.js               # Инициализация окна, IPC-мост и WinAPI вызовы
│   ├── preload.js            # Безопасный контекстный мост (contextBridge)
│   ├── torrent_worker.js     # Полнофункциональный WebTorrent воркер
│   └── installer_automation.js # Автоматизация запуска setup.exe
├── native/                   # Нативные модули на Rust, C++ и C
│   ├── lib.rs                # Rust модуль для системных операций
│   ├── process_manager.cpp   # C++ менеджер процессов Windows
│   └── crc32_fast.c          # Высокоскоростной подсчет CRC32 на C
├── src/                      # Исходный код React-приложения
│   ├── components/           # Компоненты UI (Каталог, Загрузки, Настройки)
│   ├── services/             # Сервисы (i18n, Supabase, Covers, Torrent)
│   ├── styles/               # SCSS стили интерфейса
│   ├── App.tsx               # Главный компонент приложения
│   └── main.tsx              # Точка входа React
├── package.json              # Зависимости и скрипты сборки
├── tsconfig.json             # Настройки TypeScript
└── vite.config.ts            # Конфигурация сборщика Vite
```

## 🚀 Быстрый старт для разработчиков

### 1. Требования
- **Node.js** >= 20
- **npm** >= 10

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run electron:dev
```

### 4. Сборка приложения
```bash
# Сборка фронтенда
npm run build

# Создание инсталлятора для Windows
npm run build:win

# Создание пакета для Linux
npm run build:linux
```
